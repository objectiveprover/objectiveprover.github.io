I build and organize systems according to the capacities of the human mind.

In web development, I specialize in maintaining and simplifying entire codebases and design systems, whether for clients or for open-source projects, regardless of the tools and languages involved. Outside web development, I create and modify software that makes my own work more effective. I also write from first principles about experiments and ideas, and typeset books to make them easier to read.

My work spans both design and implementation. Everything should be clear, with nothing extra and nothing missing.

1  Web Development

I’ve been a professional web developer since 2014. My goal from the beginning has been to build websites in the simplest way possible to achieve the vision of the designers who made them, down to the smallest details and with high consistency. High performance and freedom of customization are natural consequences of my approach of keeping things simple and knowing every part of the system.

Sometimes, while implementing a design, we discover structural and visual problems based on what the code looks like semantically; good design and good code go hand in hand.

1.2  Concise CSS

I started building my own CSS framework in 2014, then I found Concise CSS and noticed that Keenan Payne and I had the same vision for it. In 2015 we merged the projects and released it as a new, distinctive framework compared to the others available at the time: native HTML elements with a normalized design good enough to be used on their own, a collection of components with minimal design for easy customization, and utility styles for rapid prototyping or component variations.

It included a grid system that was more intuitive because it used HTML attributes instead of classes, which was unusual at the time, before element attributes became the default way to attach data to components.

I led the typography-oriented design for the website, following the principles of the framework; it was composed mostly of text and code samples. I wrote most of it, and Keenan helped with editing and grammar corrections (I didn’t have much experience with English yet).

The next version grew more ambitious and included its own PostCSS-based toolchain, which let us define and auto-calculate custom units for font sizes and element spacing, standardizing design systems before CSS custom properties had broad browser support.

Concise CSS was even included in some books about web development, including one by Larry Ullman, the first author I read about web development as a teenager.

The development is in a frozen state, but I plan to pick it up again and turn it into a modern framework for design systems, and quick prototyping, while retaining control over every single detail.

5  What Is a Cognitive Designer

A cognitive designer is someone who defines the structure of things based on human cognitive capacities, either perceptual or conceptual, with the goal of making them clear and understandable.

The word “designer” has been compartmentalized into different subfields (interaction designer, graphic designer, industrial designer, and so on), and when used on its own, it conveys the idea of someone who makes things pretty, and that doesn’t convey enough of myself.

But I’m against the idea of design as an artistic medium too. Art is about contemplation; design must be about action. The aesthetic side of design is secondary, yet it almost always follows on its own if a design first fulfills its purpose, and does so properly.

My goal has always been to make things as simple as possible, and I realized that “simple” meant “understandable”: something is simple when we can understand it intuitively.

I’m also a web developer, and have started to put more effort into programming recently. The principles that I use on those fields are the same as in design, but calling myself only a "designer" would undercut my work in those non-visual fields which are more about information and processes.

So what other concept could I have chosen that unifies what I do, the visual form and the internal function, and with the qualities I have chosen?
