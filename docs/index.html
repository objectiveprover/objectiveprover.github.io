  The Minimalist

A website should provide information clearly. An application should do its job and get out of the way. A novel told in letters should read like letters. Everything must have a purpose, and have the integrity to stick to it.

My goal is to reduce things to their essential qualities and making their meaning clear and legible—Removing anything that doesn’t belong, but preserve and make the essentials stand out.

  Emacs

An Emacs configuration built for clear reading and closer attention to code semantics, by omitting high-contrast coloring of all syntax. There is only high contrast between comments and code, to make emphasis in documentation.

I use it exclusively on the terminal because I find that pure text provides me with a better editing experience, without visual artifacts. And also I can edit files remotely in the same way I do locally, which I do quite often.

The environment that Emacs provides for live and interactive programming is unmatched. That has also created a strong interest for languages like Scheme and Forth.

  Concise CSS

I started building my own CSS framework in 2014; then I found Concise CSS and noticed that Keenan Payne and I had the same vision for it. In 2015 we merged the projects and released it as a new, distinctive framework compared to the others available at the time: native HTML elements with a normalized design good enough to be used on their own, a collection of components with minimal design for easy customization, and utility styles for rapid prototyping or component variations.

It included a grid system that was more intuitive because it used HTML attributes instead of classes, which was unusual at the time, before element attributes became the default way to attach data to components.

I led the typography-oriented design for the website, following the principles of the framework; it was composed mostly of text and code samples. I wrote most of it, and Keenan helped with editing and grammar corrections (I didn’t have much experience with English yet).

The next version grew more ambitious and included its own PostCSS-based toolchain, which let us define and auto-calculate custom units for font sizes and element spacing, standardizing design systems before CSS custom properties had broad browser support.

Concise CSS was even included in some books about web development, including one by Larry Ullman, the first author I read about web development as a teenager.

The project has been frozen for a couple of years, but a new version is still planned to unify all the existing components and use the latest native CSS features.
